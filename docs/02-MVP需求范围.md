# SmartTank MVP 需求范围

确认日期：2026-10-12。

本文记录需求探索中已确认的首版范围，作为原始《01 需求设计文档.docx》的补充。原始文档与本文冲突时，以本文所记录的最新决策为准。

## 产品目标与首版边界

SmartTank 是采用 C++ / Qt 的离线 Windows 储罐设计软件。产品长期面向 API 650 标准适用的储罐，“大罐”不是尺寸分类。

MVP 先完成自支撑锥顶储罐的完整基础流程：输入参数、自动排板、三维检查、基础计算校核、工程保存与重新打开，以及制造图、板件明细和计算报告导出。

软件不需要用户授权、许可证或激活机制。

## 工程与交互

- 工程以 `.st` 文件保存，支持重新打开并恢复设计数据。
- 工程空间采用左侧参数面板、中间三维可视面板、右侧组件树，顶部提供菜单和工具栏。
- 选择组件后显示对应参数；修改有效参数后更新受影响的排板和三维结果。
- 三维预览表达储罐及板件划分，支持旋转和缩放。
- 用户通过参数影响结果，不允许直接拖动板件或修改板件边界、接缝位置。
- MVP 采用简单的固定排板规则，不做材料利用率优化。

## 三维与二维对应

工程参数、排板定义和板件数据是共同设计依据。三维几何和二维制造表达分别从同一份数据生成，通过稳定的板件 ID 关联，编号、尺寸和材料信息保持一致。

板件下料轮廓由板件定义及展开、制造规则生成，不以三维截图或显示网格的投影作为下料依据。装配类视图可以使用几何投影，但不能将投影轮廓等同于展开轮廓。

首版分别处理罐底平面排板、罐壁圆柱面展开和锥顶锥面展开。具体尺寸参考面、制造余量、接缝和排板规则尚未确认，不视为已有决策。

## 基础计算与校核

- 同时覆盖罐底、罐壁和自支撑锥顶的基础厚度计算与校核。
- 点击计算后给出结果，对不合格参数提供标红等提示。
- 首版支持一种材料，材料牌号待定。
- API 650 版次及增补待定；具体公式、材料性能数据、适用条件和校核条款在实现相关计算前明确。
- 计算报告明确列出已覆盖与未覆盖的校核内容。基础校核通过不能表述为整罐已满足 API 650 全部适用要求。

## 制造图与导出

- 首版优先保证 DXF 格式，DWG 不作为 MVP 交付要求。
- CAD 仅单向导出，不支持外部修改后导回 SmartTank。
- DXF 包含罐底排板图、罐壁展开及排板图、锥顶排板图。
- 提供板件下料轮廓、尺寸与制造编号，以基本可用的图纸表达为目标，不追求复杂样式。
- 板件明细表导出为 CSV。
- 计算报告采用固定模板，具体文件格式待定。

## 后续范围

- 球顶及其他罐顶形式。
- 带支柱、梁等支撑结构的锥顶。
- 附件详图；附件建模及计算的首版范围未确认，不作为 MVP 验收承诺。
- 风、地震、锚固等专项校核。

## 待定项

以下事项保留为实现前需要解决的细节，不扩展已确认的产品范围：

1. API 650 版次及增补。
2. 单一材料牌号及适用性能数据。
3. 各部位基础厚度计算的具体项目、输入、公式和适用边界。
4. 固定排板规则、必要输入参数及板件展开的制造尺寸规则。
5. 固定模板计算报告的文件格式。

## MVP 验收主线

使用一个处于已确认计算适用范围内的自支撑锥顶储罐案例，完成以下闭环：

1. 输入工程及组件参数。
2. 自动生成罐底、罐壁和锥顶排板及三维预览。
3. 修改参数，确认对应板件与三维、二维结果一致更新。
4. 执行基础厚度计算与校核，查看结果及不合格提示。
5. 保存 `.st` 工程并重新打开，恢复设计数据。
6. 导出 DXF 制造图、CSV 板件明细及固定模板计算报告，确认板件编号、尺寸、材料及结果与工程数据一致。
