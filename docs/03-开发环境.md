# Windows 开发环境

SmartTank 已确认采用 C++、Qt Widgets、OCCT、CMake 和 MSVC。
开发依赖位于项目 `.deps/`，不进入 Git。用户运行软件不需要这些开发工具。

## 当前开发依赖

- Visual Studio 2022 Build Tools，MSVC 14.40.33807（本机已有）。
- CMake 3.29.2（本机已有）；vcpkg 自行管理构建依赖所需的辅助工具。
- Qt 6.8.3，`win64_msvc2022_64`，安装到 `.deps/Qt/6.8.3/msvc2022_64`。
- OCCT 8.0.1，使用 vcpkg 的 `x64-windows` 动态库配置构建。
- vcpkg 仓库固定于 `e456309491fd875487bf02b8a0dca76c1b1b00cc`。

Qt 包来自 Qt 官方下载仓库；OCCT 由 Microsoft vcpkg 配方下载上游源码并构建。
辅助下载工具 aqtinstall 3.3.0 安装于 `.deps/python-tools`，不修改全局 Python 包。

## 重新获取依赖

在项目根目录的 PowerShell 执行以下命令。需要网络，MSVC C++ 工具及 Windows SDK 必须已安装。

```powershell
git clone https://github.com/microsoft/vcpkg.git .deps/vcpkg
git -C .deps/vcpkg checkout e456309491fd875487bf02b8a0dca76c1b1b00cc
& ./.deps/vcpkg/bootstrap-vcpkg.bat -disableMetrics
& ./.deps/vcpkg/vcpkg.exe install opencascade:x64-windows --classic --disable-metrics
python -m pip install --target .deps/python-tools aqtinstall==3.3.0
$env:PYTHONPATH = Join-Path (Get-Location) '.deps/python-tools'
python -m aqt install-qt windows desktop 6.8.3 win64_msvc2022_64 --outputdir .deps/Qt --archives qtbase qttools qttranslations
```

## 验证依赖

`tools/dependency-check` 是独立环境验证程序：创建 Qt Widgets 对象，并用 OCCT 构造圆柱，检查头文件、链接库及运行时兼容性。它不是应用功能或制造案例。

```powershell
cmake -S tools/dependency-check -B build/dependency-check -G "Visual Studio 17 2022" -A x64 "-DCMAKE_PREFIX_PATH=$PWD/.deps/Qt/6.8.3/msvc2022_64;$PWD/.deps/vcpkg/installed/x64-windows"
cmake --build build/dependency-check --config Release
$env:PATH = "$PWD/.deps/Qt/6.8.3/msvc2022_64/bin;$PWD/.deps/vcpkg/installed/x64-windows/bin;$env:PATH"
ctest --test-dir build/dependency-check -C Release --output-on-failure
```

该检查使用 Qt 的 offscreen 平台，不验证三维 GPU 渲染；正式查看器仍需单独验证旋转缩放、板件边界及 Windows 图形驱动兼容性。

本机已完成上述 Release 配置、编译和运行检查：CTest 1/1 通过，输出 `Qt 6.8.3; OCCT 8.0.1`。OCCT 的 Debug 和 Release 开发库均已安装。

## 发布边界

发布包需包含实际使用的 Qt/OCCT DLL、Qt 平台插件及其依赖，并处理对应 VC++ 运行库。开发包、CMake、编译器和 vcpkg 不属于用户运行要求。发布前保留所用组件的许可文件并检查实际打包内容。
