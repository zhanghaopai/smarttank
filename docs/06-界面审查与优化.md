# 界面审查与优化

本次采用 qt-ui-design 检查现有 Qt Widgets 工作区，保持参数驱动的外形预览流程。

## 设计基准

中文 Windows 桌面，矩形可调整窗口，鼠标与键盘输入。默认窗口 1280×820 个逻辑像素；按约 60 cm 桌面观看距离设计。沿用系统控件、系统字体和调色板，正文至少 12 pt，标题采用正文的 1.125 倍。系统设置更大字体时保留更大值。

内容优先级：参数输入与外形预览，其次是当前结果和工程依据，最后是尚未实现的制造操作。

## 审查记录

| 分类 | 发现 | 本次处理 |
| --- | --- | --- |
| Critical | 旋转和缩放只有鼠标入口 | 增加菜单操作及键盘快捷键，复用同一查看器操作 |
| Warning | 数值验证器会拦截部分非法输入，使提交错误提示无法触发 | 提交时验证，显示字段下方的文字错误及辅助说明，保留已应用的值 |
| Warning | 多个字段共用错误区，难以判断哪个输入未应用 | 每个字段独立显示错误，修正或清空后取消提示 |
| Warning | 参数面板没有滚动容器，缩小窗口或放大字体时难以访问内容 | 增加滚动区域、表单长行换行和随字体变化的输入高度 |
| Warning | 停靠面板可浮动、关闭，容易打断工作区布局 | 参数、预览及组件树改为主窗口内的一体三列布局，移除面板窗口按钮和显隐入口 |
| Warning | 输入解析固定使用 C 区域格式 | 使用窗口的 QLocale 解析及回显数字 |
| Opportunity | 常用视角藏在菜单中，未实现操作占据工具栏 | 工具栏集中放置新建、示例、适合窗口和三种视角；排板及校核入口保留在菜单 |
| Opportunity | 工作区缺少操作说明和清晰的信息分组 | 增加预览标题、输入提示、工程依据分组、持续可见的功能范围及导航说明 |

## 操作

- 输入后按 Enter 或移出输入框应用，清空移除参数。非法输入不修改工程。
- Ctrl+0 适合窗口；Ctrl+1、Ctrl+2、Ctrl+3 分别为等轴测、正视、俯视。
- Alt+方向键旋转；Ctrl++、Ctrl+- 缩放。鼠标拖动和滚轮继续可用。
- 组件树使用方向键选择组件，空格切换显隐。
- 参数、预览和组件树固定在同一工作区，随主窗口一起调整大小，不可单独浮动或关闭。

状态和错误使用文字表达，不依赖颜色。没有新增动画；沿用系统调色板，避免为表单错误硬编码颜色。

## 验证范围

自动回归覆盖非法参数不改变已应用值、错误恢复和区域格式输入，以及原有工程、几何和工作区流程。原生查看器需要另行验证渲染、旋转缩放与截图。

本次已通过 preview 构建和全部 3 项 CTest；Windows 原生工作区测试 9 项通过，示例窗口截图已检查，当前系统 DPI 下参数、导航说明及结果状态均可见。

尚未完成辅助技术端到端审查、系统大字体和不同 DPI 组合的完整人工验收，以及色觉模拟。因此本次调整不代表完整的 WCAG 合规认证。工程保存、排板、校核和制造导出仍保持当前未实现状态。
