# 当前版本操作说明

本版完成 SmartTank 的应用框架及共同数据基础，尚未完成 MVP 闭环。

## 启动与参数输入

构建后，在项目根目录运行 `./tools/run.ps1`，启动本地应用，无登录、激活或网络前置条件。

右侧组件树仅提供罐底、罐壁和自支撑锥顶。选择组件，左侧显示相应基础尺寸参数。
所有数值初始为空，输入正数并按 Enter 或离开输入框后应用；清空可恢复为未输入。
输入错误时显示原因，本次输入不写入工程。

目前参数包括罐壁直径/高度、锥顶升高及三部位厚度。这些基础参数不代表排板参数集合、尺寸参考面或制造规则已经确定；相关规则确认后再补充所需参数。

## 三维视图与结果状态

OCCT 查看器支持按共同板件的安装曲面边界创建平面、圆柱面和锥面表达，通过板件 ID 映射显示对象。
有有效显示板件时，按住鼠标左键拖动旋转，滚轮缩放，点击“适合窗口”调整视图；组件树选择可高亮对应部位。

输入罐体直径和罐壁高度后，中央显示罐底和罐壁；补充锥顶升高后显示完整外形。
清空直径或高度会撤下外形，清空锥顶升高会撤下罐顶。参数应用后外形自动更新，不保留与输入不符的旧模型。

组件树中的复选框控制显隐，选择组件可高亮。视图菜单提供等轴测、正视、俯视和适合窗口。
“载入示例尺寸”设置直径 6000 mm、罐壁高度 4000 mm、锥顶升高 800 mm，仅用于展示；已有输入时会先确认替换。也可用 `./tools/run.ps1 -Example` 打开示例。

由于排板生成规则尚未确认，当前应用不生成真实制造板件。中央明确标示“外形预览”，不显示制造接缝或模拟板件划分；该几何不计入工程板件列表，不使排板结果成为有效结果。
外形为零厚度组件曲面，不用于计算制造厚度、下料轮廓或校核。测试中的板件仍只存在于测试程序中，没有作为新工程默认值。

生成结果绑定其输入修订。修改输入后，旧排板/校核结果失效，旧修订的延迟结果不能替换当前结果。
查看或切换组件不会改变工程输入。制造轮廓与安装曲面分别存储，不从显示网格提取尺寸。

## 尚不可用的操作

- “生成排板”提示排板及制造规则未确定，不产生板件或有效制造结果，已有外形预览继续显示。
- “计算校核”提示标准、材料及公式规则未确定，不生成通过结论。
- 导出菜单提示当前没有有效制造几何或计算结果，不创建输出文件。
- 保存与打开暂不可用，关闭应用后本次输入不会保留。新建工程时若已有输入，会提示确认清空。

## 已验证范围

Release 构建、无窗口启动及工作区交互、板件身份与结果失效机制已通过测试。
Windows 原生图形测试验证三种安装曲面、板件显示、旋转缩放及制造数据不变；同时验证实际工作区外形随尺寸更新、组件显隐、清空输入及预览不生成制造结果。
这些检查不代表已完成制造案例验证、标准校核或完整断网闭环验收。
