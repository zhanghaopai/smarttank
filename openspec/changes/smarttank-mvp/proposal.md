# Proposal

## Why

SmartTank 需要验证离线储罐设计的完整闭环，并确保三维预览与二维制造图来自一致的工程及板件数据。以自支撑锥顶储罐为 MVP，避免首次交付扩展到所有 API 650 罐型及专项校核。

需求依据为 `docs/02-MVP需求范围.md` 及已确认探索结论；请求中的 `docs/mvp需求范围.md` 当前不存在。

## What Changes

- 规划 C++ / Qt 离线 Windows 应用，无许可证、激活或用户授权机制。
- 支持 `.st` 工程保存、重开，参数面板、三维可视区和组件树。
- 建立共用工程、排板与板件数据，采用固定规则的参数驱动自动排板；不允许手工编辑板件及接缝，不做材料利用率优化。
- 同时覆盖罐底、罐壁、自支撑锥顶的基础厚度计算与校核，标示不合格项。
- 分别生成三维预览及二维制造表达，通过稳定板件 ID 对应；下料轮廓依据展开和制造规则，不依据显示网格投影。
- 单向导出 DXF 制造图、CSV 明细及固定模板报告，不支持 CAD 回导。
- 球顶、带支撑结构锥顶、附件详图、风/地震/锚固专项校核留到后续；附件建模与计算未承诺纳入 MVP。
- 标准版次、单一材料、校核公式和边界、排板与制造尺寸规则、报告格式均待确认，不选择默认值代替确认。

## Capabilities

### New Capabilities

- `tank-project`: 离线工程、参数编辑、保存重开与首版罐型边界。
- `plate-layout`: 参数驱动排板、共用板件数据及三维/二维对应。
- `tank-calculation`: 三部位基础厚度校核、结果提示及适用范围表达。
- `manufacturing-export`: DXF 制造图、CSV 明细及固定模板报告单向导出。

### Modified Capabilities

无。当前主规格库为空。

## Impact

规划开始时仓库只有需求文档、README 和 OpenSpec 配置；当前实施已建立 C++ / Qt 基础应用、构建与测试配置。原始需求和主规格未修改，实施进度以任务清单为准。

后续实施涉及桌面 UI、工程数据、持久化、排板几何、基础计算及文件导出。已确认采用 Qt Widgets、CMake、MSVC 和 Open CASCADE Technology（OCCT）三维预览；Qt 6.8.3 与 OCCT 8.0.1 开发依赖已配置并通过联合编译运行检查，OCCT 原生查看器已接入工作区。真实排板与查看器联动、制造几何实现、DXF 库、`.st` 内部编码仍待完成或确定。

规划产物完整不代表工程计算依据已就绪；相关实现和验收必须先完成待定事项确认。

## Current Implementation Progress

当前完整任务为 4/35：应用工程、共同板件数据、设计修订与结果失效机制、基础工作区已完成。用户要求优先完成三维视图，当前已具备参数驱动的罐底、罐壁及自支撑锥顶外形预览，以及旋转缩放、组件高亮/显隐、等轴测/正视/俯视和显式载入示例尺寸。

外形预览不包含真实板件划分和制造接缝，不计入制造板件列表，不生成有效排板、校核或制造输出；任务 4.2、4.3 保留未完成。保存重开、基础计算、固定排板、制造输出及完整闭环仍待相应前置条件。

Release 构建、3/3 自动测试、两项 Windows 原生图形测试及 OpenSpec 严格校验通过。详细检查点与后续入口见 `tasks.md`，具体三维表达边界见 `design.md`。
